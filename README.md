# RetailIQ – AI-Powered Inventory Intelligence

Enterprise Inventory Monitoring, Forecasting, and Automated Replenishment Agent.

## Deployment to Vercel (100% Pre-Configured)

1. **Push to GitHub**:
   ```bash
   git add .
   git commit -m "RetailIQ: Production-ready fullstack deployment"
   git push -u origin main
   ```

2. **Deploy on Vercel**:
   - Go to [vercel.com/new](https://vercel.com/new)
   - Import your repository (e.g. `Sai-Babud4/Store-IQ`).
   - Framework preset: **Vite** (detected automatically).
   - Click **Deploy**!
